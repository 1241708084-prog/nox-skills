# nox-skills

产品经理自用市场调研技能（偏向于国内市场版本）。

围绕实体消费品、潮玩、玩具、食品、礼盒及 IP 衍生品，整理可复用的产品分析工作流。

## 已收录技能

| 技能 | 用途 | 说明 |
| --- | --- | --- |
| [NOX Competitive Snapshot](skills/nox-competitive-snapshot/SKILL.md) | 聚焦 2–5 个竞品或标杆，比较购买理由、包装玩法、价格与制造难度，形成开发建议 | [中文说明与示例](skills/nox-competitive-snapshot/README.md) |

## 安装

在 Codex 中发送：

```text
请安装这个技能：https://github.com/1241708084-prog/nox-skills/tree/main/skills/nox-competitive-snapshot
```

也可以下载仓库，将 `skills/nox-competitive-snapshot` 整个文件夹复制到个人技能目录：

- Windows：`%USERPROFILE%\.codex\skills\nox-competitive-snapshot\`
- macOS / Linux：`~/.codex/skills/nox-competitive-snapshot/`

确保 `SKILL.md` 直接位于该文件夹下。

## 使用示例

```text
用 $nox-competitive-snapshot 对比 3 个适合年轻人送朋友的糖果礼盒。
重点看购买理由、内容物组合、包装玩法和生产难度。
区分事实与判断，注明来源，再给 3 个可借鉴动作、2 个风险和 1 个优先建议。
```

已有商品时提供具体链接、目标人群、渠道和计划售价，可以缩小分析范围。

## 数据与使用边界

技能提供分析方法，不附带实时销量数据库、平台后台权限或付费数据接口。近期销售核查需要宿主搜索工具或用户提供有授权的资料。

店铺排名不等于单品销量，历史累计不等于本期成交，缺货不等于已证明热销。品牌自述、监测估计、用户反馈应分别标注，成本判断不能替代供应商报价。
