# NOX Competitive Snapshot

## Scope first
State: product/category, decision, competitors, price/channel boundary.
If competitors are not specified, choose only the few that best affect the decision.

## Compare by buying logic, not feature count
For physical consumer products, prioritize:
- target buyer / recipient;
- price and perceived value;
- hero product / hero visual;
- product bundle and giftability;
- packaging structure;
- IP/brand integration;
- collectability / repeat-purchase mechanic;
- channel and promotion mechanic;
- manufacturing complexity / likely cost burden;
- consumer proof or attention signal.

## Output
### 1. Competitor snapshots
Max 5–7 bullets each. Separate observed fact from judgment.

### 2. Comparison matrix
Use only dimensions that matter to the decision. Do not create a 20-row feature graveyard.

### 3. What they are actually selling
For each competitor, state the underlying purchase reason in one sentence: nostalgia, gifting face, celebrity/fandom identity, cute collectability, value bundle, novelty, convenience, etc.

### 4. Gaps and traps
- gaps worth testing;
- crowded mechanics to avoid copying;
- attractive-looking ideas that rely on capabilities the user does not have.

### 5. Product implications
Give:
- 3 moves worth borrowing/adapting;
- 2 risks;
- 1 clear recommendation for the current product.

## Evidence discipline
A brand’s own page proves what it claims, not that consumers agree. Treat reviews, user posts, sales rankings, platform data, press, and official statements differently. Never fabricate sales or market share.
