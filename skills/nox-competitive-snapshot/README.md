# NOX Competitive Snapshot

面向实体消费品的竞品与标杆商品分析技能，适用于潮玩、玩具、礼盒、食品及 IP 衍生品等产品开发工作。

聚焦 2–5 个相关案例，比较消费者为什么买、售价与感知价值、产品组合、包装结构、收藏与复购机制、渠道及制造难度，输出可供产品决策使用的建议。

## 适合什么时候用

- 有了产品方向，想知道应该研究哪几个竞品，以及各自值得参考的地方。
- 发现一款热门商品，想拆解消费者购买理由与可复用的产品机制。
- 准备开发礼盒、潮玩或 IP 衍生品，需要比较包装、内容组合、礼赠场景和成本负担。
- 要向团队汇报，希望把零散案例整理成有结论的对比和开发建议。

适用于产品经理、商品企划、设计师及实体消费品开发团队。范围以小规模、聚焦决策的分析为主；完整行业研究和实时销量监测需要额外工具与数据。

## 核心分析思路

先确定要做的产品和决策，再挑选少量最相关的案例。比较重点是购买逻辑：谁买、送给谁、为什么愿意付钱，以及产品怎样通过造型、玩法、包装或内容组合兑现价值。

分析不会只罗列品牌与功能，也会关注生产复杂度，以及某个成功案例是否依赖授权 IP、明星粉丝、渠道资源或品牌积累。最后把观察转成可以测试的开发动作。

## 主要比较维度

| 维度 | 要回答的问题 |
| --- | --- |
| 目标人群与场景 | 谁购买、谁使用，是自用、收藏还是送礼？ |
| 售价与感知价值 | 消费者认为钱花在了哪里？ |
| 核心产品与视觉 | 哪个造型、内容或动作最容易被记住？ |
| 组合与包装 | 包装是否参与使用，吃完或玩完是否有留存价值？ |
| IP 与复购机制 | 购买依赖角色喜爱、收藏、换装还是消耗补充？ |
| 渠道与传播 | 商品怎样被发现，卖点能否直观演示？ |
| 制造与成本负担 | 哪些结构、材料或装配步骤会增加落地难度？ |
| 消费证据 | 有哪些成交、评价或用户反馈支持判断？ |

维度按任务取舍，不要求每次全部填写。

## 输出内容

1. 竞品简析：区分观察事实与分析判断。
2. 对比矩阵：仅保留影响当前决策的维度。
3. 购买理由：说明每个案例实际满足什么需求。
4. 机会与陷阱：哪些值得测试，哪些依赖难以复制的能力。
5. 产品启示：3 个可借鉴动作、2 个风险、1 个明确建议。

## 使用示例

```text
用 nox-competitive-snapshot 分析 3–5 个适合年轻人送礼的玩具或糖果礼盒，
先核实具体商品和销售证据，再比较购买理由、包装玩法与生产难度，
给出可借鉴的开发方向，并明确区分事实和判断。
```

也可以提供具体竞品链接、目标客群、销售渠道、预算或计划售价，帮助缩小分析范围。

### 已有商品，想看改进方向

```text
用 nox-competitive-snapshot 对比我提供的三个礼盒链接。
目标是年轻女性自用和朋友送礼，计划售价 59–99 元。
重点看包装结构、内容物组合和留存价值，给出三个可测试的改进动作。
```

### 有方向，尚未确定竞品

```text
用 nox-competitive-snapshot 为“玩具＋糖果”礼盒选 3 个相关标杆。
比较购买理由、可玩性、食品与玩具的组合方式和生产复杂度。
分开标注已知事实、分析判断和待验证假设。
```

### 需要近期热销证据

```text
用 nox-competitive-snapshot 拆解最近 30 天有成交证据的具体商品。
每个商品注明 SKU、市场、统计周期、销量或销售额、数据来源。
区分单品与店铺、累计与本期数据；证据不足时减少案例数量。
再分析值得借鉴的产品机制，不能只凭上新或缺货判断热销。
```

以上为推荐提问方式。时间筛选和证据获取取决于宿主搜索工具，本技能本身不提供销量查询接口。

## 一个合适的结果应包含什么

以糖果礼盒为例，结果应说明某款商品是靠分次拆盒、特殊吃法、角色收藏还是分享场景吸引购买，并给出相关事实与来源。随后判断哪些机制适合当前预算与渠道，哪些依赖难以复制的资源。

如果只有品牌新品页，就只能说明商品设计和品牌主张；如果有具体成交记录，才能在相应市场与统计周期内讨论销售表现。预测成本、目标售价和新概念应明确为估计或待测试假设。

## 与搜索工具怎么配合

搜索工具负责找到近期商品、公开成交信息和用户反馈；本技能负责挑选相关案例、组织对比并形成产品建议。两者可以配合使用，但搜索热度、品牌知名度和缺货状态都不能自动替代成交证据。

## 安装

将本仓库下载后，把包含 `SKILL.md` 的文件夹命名为 `nox-competitive-snapshot`，放入 Codex 的个人技能目录：

- Windows：`%USERPROFILE%\.codex\skills\nox-competitive-snapshot\SKILL.md`
- macOS / Linux：`~/.codex/skills/nox-competitive-snapshot/SKILL.md`

## 文件与边界

- `SKILL.md`：技能指令。
- `README.md`：用途、安装和使用说明。

本技能提供分析工作流，不附带付费电商数据库、登录凭据或实时销量接口。搜索能力取决于宿主工具和可访问的数据源。品牌自述、用户评论、平台排名与成交数据应分别处理；不得编造销量或市场份额。

公开页面上的数据也可能来自第三方估计或品牌自行披露，应保留其统计周期、适用市场与口径限制。制造复杂度与成本判断不能替代供应商报价；产品建议不能保证销量或商业回报。
